# 📚 Library Book Demand Prediction

A Machine Learning based Streamlit application that predicts future library book demand using historical circulation data.

## 🚀 Live Demo

👉 [Open Library Book Demand Prediction App](https://library-book-demand-prediction-fkn34nmpqydmxymtcwaepx.streamlit.app/)

## 🧠 Machine Learning Model

- Random Forest Regressor
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## ✨ Features

- 📖 Book Category Selection
- 📅 Month Selection
- 🎓 Academic Semester
- 👨‍🎓 Number of Students
- 📚 Previous Borrowing Count
- 📊 Previous Demand Count
- 🔮 Demand Prediction
- 📈 Monthly Demand Visualization
- 📚 Category-wise Analysis
- 🤖 Model Performance

- `app.py` – Main Streamlit application
